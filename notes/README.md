# Product Notes

A small, curated set of notes from building AI products and working with AI-assisted delivery.

These are not a complete archive of my writing. I keep this section intentionally selective: each note should capture a product or systems judgment that I expect to remain useful beyond the tool or model version that prompted it.

English is the primary version here, with a Chinese version linked from each note.

## Published

### [AI Cost Is a Product Architecture Problem](./ai-cost-is-a-product-architecture-problem.md)

What changed when I stopped treating AI cost as a token-pricing problem and started treating it as part of product architecture: deterministic/model boundaries, context selection, shared call controls, budget reservation, attempt-level accounting, and quality checks after optimization.
